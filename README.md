# 2人用WebRTCビデオ通話

## PCでローカル起動

Node.js 18以上をインストールしてから、このフォルダで:

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

「通話ルームを作る」を押すと専用URLが作られます。

## インターネット上で公開する場合

このアプリはNode.js + Express + Socket.IOを使います。
HTTPSで公開してください。カメラ・マイクはHTTPSまたはlocalhostでないとブラウザから利用できない場合があります。

### 注意
このサンプルは2人制限、ログインなし、URLを知っている人が参加できる方式です。
URLを第三者に公開すると、その人が部屋に入れる可能性があります。

また、STUNのみなので、一部のネットワークではWebRTC接続が成立しないことがあります。
本番運用で接続成功率を上げる場合はTURNサーバーを追加してください。
